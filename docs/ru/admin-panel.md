# Админ-панель

Всё, что владелец делает изо дня в день, собрано в **панели управления внутри Telegram** из кнопок. Откройте её, отправив боту `/admin`. Пользоваться могут только администраторы.

> English version: [../admin-panel.md](../admin-panel.md)

## Как стать администратором

Подойдёт любой способ, их можно сочетать:

- **Ссылка в одно касание.** `funnelbot setup` (или `funnelbot link`) печатает `https://t.me/your_bot?start=claim_...`. Откройте её и нажмите Start. Работает, только пока у бота нет администратора, так что потом бота никто не украдёт.
- **Ваш Telegram id в настройках.** Отправьте боту `/id` и впишите число в `bot.admins` (или `ADMIN_ID` в `.env`).

## Меню

| Кнопка | Что делает |
|---|---|
| **📊 Статистика** | Клиенты (за сутки, за неделю), покупатели и конверсия, платежи, возвраты, ожидающие заказы, действующие доступы, выручка по валютам (всего, за 7 дней, за 24 часа), где клиенты сейчас в воронке, источники трафика |
| **👥 Клиенты (CSV)** | Присылает таблицу всех клиентов с их ответами, источником и покупками. Открывается в Excel и Google Таблицах |
| **🛠 Собрать воронку** | Создавать и править шаги, кнопки, продукты, напоминания, вопросы и доступ в канал кнопками: [Сборка воронки в Telegram](funnel-builder.md) |
| **📣 Рассылка** | Пошаговая рассылка группе клиентов (ниже) |
| **💳 Платежи** | Последние заказы. Нажмите на заказ, чтобы увидеть детали и кнопку **«Вернуть деньги»** |
| **🔎 Найти клиента** | Отправьте id или @username, откроется карточка клиента |
| **🩺 Проверка бота** | Проверяет права бота в каждом канале, платёжные сервисы и заказы, ожидающие выдачи |
| **🔄 Перезагрузить воронку** | Заново читает `funnel.yaml` без перезапуска. Если в файле ошибка, работает старая версия, а вы видите, что исправить |

## Рассылка

1. Нажмите **«Рассылка»**.
2. Пришлите сообщение, которое нужно доставить, ровно в том виде, как его увидят клиенты: текст, фото, видео, голосовое или файл, с оформлением. Бот копирует его, ничего не теряется.
3. Выберите получателей. На каждой кнопке указано, сколько это человек:
   - **Всем**, **Покупателям**, **Ещё не купили**, **С действующим доступом**, **Доступ закончился**, **Только мне (тест)**;
   - **По шагу**: клиенты, которые сейчас на выбранном шаге воронки;
   - **По источнику**: клиенты, пришедшие по выбранной ссылке `?start=`.
4. Проверьте число в подтверждении и нажмите зелёную кнопку **«Отправить»** (или красную **«Отмена»**).

Подробности: сообщения уходят в безопасном темпе, с большим запасом до лимитов Telegram. Клиенты, заблокировавшие бота, пропускаются и отмечаются. Клиенты, нажавшие `/stop`, рассылок не получают. Если сервер перезапустился посреди рассылки, она продолжится с того места, где остановилась. По завершении вы получите итог.

### Откуда пришли клиенты

Дайте каждому источнику трафика свою ссылку: `https://t.me/your_bot?start=ads1`, `...?start=blogger_ivan`. Первая использованная ссылка запоминается, показывается в статистике и доступна как аудитория для рассылки.

## Карточка клиента

**«Найти клиента»** (или **«Клиент»** из заказа) показывает: имя, @username, источник, текущий шаг, согласие, заблокировал ли бота, ответы на ваши вопросы, все заказы и все доступы. Кнопки:

- **🎁 Выдать доступ**: выберите продукт, клиент получит его так, как если бы оплатил (сообщение, файлы, ссылка в канал).
- **⛔ Забрать доступ**: выберите доступ в канал, клиента удалят из канала.
- **🗑 Стереть данные**: после подтверждения стирает личные данные и закрывает доступ. Записи о заказах остаются для бухгалтерии.

## Возвраты

**«Платежи»** → нажмите заказ → **«Вернуть деньги»** → подтвердите. Stars возвращаются автоматически. Для других способов вы возвращаете деньги в самом сервисе, а заказ помечается возвращённым. Доступ, выданный заказом, закрывается.

## Уведомления

Бот пишет в чат менеджеров (или вам, если чата нет), когда нужно внимание: платёж без заказа, двойной платёж, неудавшаяся выдача, которая повторяется, нехватка прав бота в канале, отказ платёжного сервиса. Каждый вид уведомления приходит не чаще раза в час.

## Команды (по желанию)

Каждое действие панели есть и командой, для тех, кто любит печатать:

| Команда | Значение |
|---|---|
| `/admin` | Открыть панель |
| `/stats`, `/leads`, `/payments` | Статистика, CSV, последние заказы |
| `/user <id или @имя>` | Карточка клиента текстом |
| `/grant <id или @имя> <продукт>` / `/revoke <id или @имя> <продукт>` | Выдать или забрать доступ |
| `/refund <номер заказа>` | Возврат |
| `/erase <id или @имя>` | Стереть личные данные |
| `/broadcast <сегмент>` (ответом на сообщение) | Разослать сообщение, на которое отвечаете. Сегменты: `all`, `paid`, `unpaid`, `active`, `expired`, `test`, `step:<id>`, `source:<имя>` |
| `/reload` | Перезагрузить воронку |
| `/managerchat` | Сделать текущий чат чатом менеджеров (отправьте в группе, где есть бот) |
| `/id` | Показать ваш id и id текущего чата (работает для всех) |

## Команды клиента

`/help`, `/terms` (ваши документы), `/paysupport` (помощь с оплатой с кнопкой связи с вами), `/deleteme` (удалить мои данные), `/stop` и `/resume` (выключить и включить рекламные сообщения; уведомления о доступе всё равно приходят). Помощь по оплате и удаление данных требуют правила Telegram, поэтому они доступны всегда.
