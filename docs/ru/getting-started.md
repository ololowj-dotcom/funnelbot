# Быстрый старт

Эта страница проведёт вас от нуля до работающего бота для продаж. Программировать не нужно. Хватит примерно 10 минут.

> English version: [../getting-started.md](../getting-started.md)

## Что понадобится

1. **Аккаунт в Telegram.** Из него вы создадите бота и будете им управлять.
2. **Место, где бот работает круглосуточно.** Проще всего небольшой Linux-сервер (VPS): Ubuntu 22.04 или новее, либо Debian 12, с 512 МБ памяти. Подойдёт любой хостинг. **Домен, HTTPS и открытые порты не нужны.** Если хотите только попробовать, хватит своего компьютера (см. [Запуск на своём компьютере](#запуск-на-своём-компьютере)).

## Шаг 1. Создайте бота в Telegram

Любой Telegram-бот создаётся через специального бота BotFather.

1. Откройте Telegram, найдите **@BotFather** (у него синяя галочка) или откройте <https://t.me/BotFather>.
2. Отправьте `/newbot`.
3. BotFather спросит **имя** (его увидят клиенты, например «Мой клуб») и **username** (должен заканчиваться на `bot`, например `my_club_bot`).
4. BotFather пришлёт сообщение с **токеном**: строкой вида `123456789:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw`. Скопируйте её. **Тот, у кого есть токен, управляет вашим ботом, поэтому не публикуйте его.** Если токен утёк, отправьте BotFather `/revoke`, чтобы получить новый.

По желанию: `/setuserpic` задаст картинку бота, `/setdescription` задаст текст, который клиенты увидят до нажатия Start.

## Шаг 2. Установите funnelbot на сервер

Подключитесь к серверу по SSH (адрес и пароль или ключ показывает ваш хостинг). Затем выполните одну команду:

```bash
curl -fsSL https://raw.githubusercontent.com/ololowj-dotcom/funnelbot/main/install.sh | sudo bash
```

Если вы уже `root`, `sudo` не нужен. Установщик:

- поставит Python и git, если их нет (семейства Debian, Ubuntu, Fedora, CentOS/RHEL);
- установит funnelbot в `/opt/funnelbot` и добавит команду `funnelbot`;
- запустит пошаговую настройку.

## Шаг 3. Ответьте на вопросы настройки

Настройка спросит три вещи:

1. **Токен** от BotFather. Он сразу проверяется в Telegram, поэтому опечатка находится на месте и можно вставить токен ещё раз.
2. **Язык** бота: `ru` (по умолчанию) или `en`.
3. **Кто управляет ботом.** Нажмите Enter, чтобы получить ссылку в одно касание (проще всего), либо введите свой Telegram id.

Затем она предложит **запускать бота в фоне и после каждой перезагрузки сервера**. Ответьте `y`.

В конце она покажет ссылку вида `https://t.me/my_club_bot?start=claim_...`.

## Шаг 4. Станьте администратором

Откройте показанную ссылку в Telegram и нажмите **Start**. Бот ответит «Теперь вы администратор этого бота» и покажет кнопку, открывающую панель управления. Ссылка работает, только пока бота никто не занял, поэтому посторонние потом ею воспользоваться не смогут.

Дальше в любой момент отправляйте боту `/admin`, чтобы открыть панель: статистика, рассылки, платежи, клиенты, проверка бота. Всё кнопками.

## Шаг 5. Соберите воронку в боте

Настройка создала небольшую стартовую воронку в `/opt/funnelbot/bot/`. Откройте бота и нажмите Start: он поприветствует вас и подскажет, куда идти дальше.

Теперь соберите свою. Отправьте `/admin` и нажмите **🛠 Собрать воронку**. Кнопками и короткими сообщениями можно:

- создать **продукт** (название, цена и что получит клиент: доступ в закрытый канал на несколько дней, сообщение с файлом или заявка менеджеру);
- написать **шаги** (сообщения, которые видят клиенты) и добавить к ним **кнопки** синего, зелёного или красного цвета;
- добавить **напоминания**, **вопросы** (email, телефон) и картинки;
- нажать **▶️ Посмотреть глазами клиента**, чтобы проверить.

Полное руководство с примером на 5 минут (платный закрытый канал): [Сборка воронки в Telegram](funnel-builder.md).

Всё, что вы соберёте, сохраняется в `/opt/funnelbot/bot/`:

| Файл | Что это |
|---|---|
| `funnel.yaml` | Ваша воронка. Читаемый файл, его можно править и руками |
| `funnel.yaml.bak` | Предыдущая версия, сохраняется автоматически |
| `.env` | Секреты: токен, позже ключи оплат. Никому не показывайте |
| `funnelbot.db` | Появится после первого запуска: клиенты, заказы, доступы |

Если удобнее текстовый файл, отредактируйте его (`nano /opt/funnelbot/bot/funnel.yaml`), выполните `funnelbot validate -f /opt/funnelbot/bot/funnel.yaml` и нажмите **«Перезагрузить воронку»** в `/admin`. Чтобы прорепетировать полную демо-воронку в терминале, включая оплаты и ход времени: `funnelbot init demo --sample` и `funnelbot preview -f demo/funnel.yaml`.

## Шаг 6. Подключите оплаты и закрытый канал

- **Telegram Stars** работают сразу, аккаунты не нужны, и включены по умолчанию. Цены в Stars.
- Для карт, ЮKassa, крипты и ручного перевода нужны ключи этих сервисов: [Оплаты](payments.md).
- Чтобы продавать доступ в закрытый канал, подключите его: [Доступ в закрытый канал](private-channel-access.md).

До прихода настоящих клиентов включите тестовый режим (`/admin` → **Собрать воронку** → **Оплаты и язык** → **Включить тестовый режим**), купите свой продукт бесплатной тестовой кнопкой, а затем откройте `/admin` → **«Проверка бота»**. Перед запуском выключите тестовый режим.

## Запуск на своём компьютере

Удобно для пробы. Бот работает, только пока компьютер включён и в сети.

1. Установите Python 3.10 или новее с <https://www.python.org/downloads/> (в Windows отметьте «Add python.exe to PATH»).
2. Откройте терминал и выполните:

   ```bash
   python -m pip install "git+https://github.com/ololowj-dotcom/funnelbot"
   funnelbot setup
   ```

3. Запустите бота и не закрывайте окно:

   ```bash
   funnelbot run
   ```

## Запуск в Docker

```bash
git clone https://github.com/ololowj-dotcom/funnelbot && cd funnelbot
docker compose run --rm funnelbot init /data --token 123456789:AAH... --lang ru
docker compose up -d
docker compose run --rm funnelbot link -f /data/funnel.yaml
```

Последняя команда покажет ссылку «стать администратором». Воронка и база лежат в папке `bot/` рядом с `docker-compose.yml`.

## Если что-то не работает

Запустите `funnelbot doctor`. Он проверит токен, каналы и ключи оплат и простыми словами скажет, что исправить. Ещё помощь: [Вопросы и проблемы](faq.md).
